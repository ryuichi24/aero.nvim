# Coding Conventions

Before writing or modifying code, read and follow the conventions for each
language being changed:

- **Go:** [Go Coding Conventions](./go.md).
- **Lua:** [Lua Statement Spacing](./lua.md).
- **TypeScript:** [TypeScript Coding Conventions](./typescript.md).
- **TypeScript/React:** Also follow [React Coding Conventions](./react.md).

For changes involving multiple languages, follow each applicable document.
Use the project's existing formatter, linter, and type checker.
